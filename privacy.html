Wpad+ Privacy Policy

Effective date: September 10, 2026

Summary: Wpad+ keeps notes and settings locally in the user's browser. The developer does not collect, receive, sell, or share this data.

Data processed by the extension

Wpad+ processes user-generated note text, page bookmarks, the selected interface language, editor settings, and window state. This information is used only to provide the notebook's user-facing features.

Local storage and retention

All notes and settings are stored locally in the extension's browser storage. They are not transmitted to the developer or to external servers. Data remains on the user's device until the user deletes it, clears the extension's storage, or removes the extension.

Import and export

JSON backup import and export, and TXT page export, happen only when initiated by the user. The resulting files remain under the user's control and are not uploaded by Wpad+.

Sharing, sales, advertising, and analytics

Wpad+ does not sell or share user data, use it for advertising or credit decisions, or provide it to third parties. The extension does not include analytics, tracking, accounts, or remote code.

Browser access

The extension requests only the Chrome sidePanel permission so its interface can be displayed in the browser side panel. Wpad+ does not read websites, browsing history, page content, cookies, or open-tab data.

User control

Users can edit or delete notes inside Wpad+, export a backup, clear the extension's local data, or uninstall the extension at any time.

Changes to this policy

If Wpad+'s data practices change, this policy and the Chrome Web Store disclosures will be updated before the change is released.

Contact

Questions about this policy can be submitted through the Wpad+ GitHub issue tracker.
